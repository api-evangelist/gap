## What a developer or agent can and cannot do here

- There is **no public Gap Inc. API**. No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf
  or WSDL contract is published on any Gap-controlled host.
- There is **no MCP server and no A2A agent card**. Probes of /.well-known/agent-card.json,
  /.well-known/agent.json, /mcp and /.well-known/mcp.json on eight Gap hosts all returned 404
  (2026-09-10).
- `api.gap.com` **is** a live Apigee gateway, but it exposes no proxy to an anonymous caller;
  it fronts Gap's own web and mobile clients.
- `developer.gap.com` is a DNS CNAME to `gap-api-docs-portal.apigee.net`. The service behind
  it is gone and its TLS certificate does not cover the hostname, so it cannot be reached.
- Gap Inc. **does** run a vulnerability disclosure programme, on HackerOne.
- Gap Inc.'s robots.txt at www.gap.com explicitly names AI crawlers — ClaudeBot, GPTBot,
  OAI-SearchBot, ChatGPT-User, PerplexityBot, Amazonbot, Meta-ExternalAgent, YouBot, CCBot,
  Bingbot, Googlebot — in a group with `Allow: /`, while disallowing /buy/, /checkout/,
  /profile/, /shopping-bag and the site-search and error paths. Catalogue browsing is
  permitted to agents; transactional paths are not.

## Notes for agents

- Gap.com customer-service pages require their `?cid=` query parameter. Without it the site
  answers HTTP 200 with an error body ("We're sorry. An error occurred that prevented this
  page from being displayed") — a soft 404. Do not treat a 200 from gap.com as proof a page
  exists; read the body.
- www.gap.com serves an HTML shell for `/llms.txt`. It is not an llms.txt document.
